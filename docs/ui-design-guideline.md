# 《纸片人男友》UI 设计系统与页面视觉规范

> 本文档约束 Trae 后续所有页面实现的视觉表现。
> 不得修改产品流程、页面结构、角色设定、数据库结构、API 边界、AI 能力边界和 MVP 不做事项。

---

## 1. 整体视觉方向

### 关键词

```text
柔和    安静    低饱和    有留白    轻微恋爱感    像真实私聊    有一点氛围
```

### 产品气质

更像一个**高级的私密聊天陪伴产品**，不是：

```text
乙女页游（避免华丽边框、闪动特效、抽卡感）
AI 工具站（避免科技蓝、代码感、参数面板）
SaaS 后台（避免数据表格、管理菜单、操作按钮区）
```

### 设计原则

```text
1. 安静优先：不要热闹，不要堆叠元素。
2. 呼吸感：留白是设计的一部分，不是没做完。
3. 一致性：所有页面共享同一套色彩和组件语言。
4. 移动端优先：核心场景在手机，桌面端居中展示。
5. 情绪细腻：加载、失败、空状态都要柔和，不刺眼。
```

## 2. 色彩系统

### 主色调

采用**低饱和暖色系**，避免廉价感和过度甜腻：

| 名称 | 色值 | 用途 |
|------|------|------|
| 背景主色 | `#FAF7F5` | 页面底层背景、聊天页背景 |
| 背景次色 | `#F5F0EC` | 卡片背景、输入区背景、菜单背景 |
| 主色 | `#D4A5A5` | 用户气泡、主按钮、强调元素 |
| 主色hover | `#C99595` | 按钮悬停态 |
| 辅助色 | `#B8A9C9` | 标签、次要强调、角色差异化点缀 |
| 辅助色2 | `#D9C4B0` | 温暖点缀、分割线、边框 |

### 文字色

| 名称 | 色值 | 用途 |
|------|------|------|
| 文字主色 | `#4A4441` | 标题、正文、角色名 |
| 文字次色 | `#8A827E` | 副标题、时间戳、提示文字 |
| 文字浅色 | `#A69E9A` | 占位符、禁用态、极次要信息 |
| 文字反色 | `#FFFFFF` | 主按钮文字、深色背景上的文字 |

### 聊天气泡色

| 名称 | 色值 | 用途 |
|------|------|------|
| 男友气泡 | `#F0EBE6` | 男友消息气泡背景 |
| 男友气泡边框 | `#E8E2DC` | 男友气泡微弱边框 |
| 用户气泡 | `#E8D5D5` | 用户消息气泡背景（柔和浅粉） |
| 用户气泡边框 | `#D4C4C4` | 用户气泡微弱边框 |

### 状态色

| 名称 | 色值 | 用途 |
|------|------|------|
| 成功 | `#A3C9A8` | 成功提示（极少使用） |
| 警告 | `#E8D5A3` | 额度用完、轻量提示 |
| 错误 | `#D4A5A5` | 失败状态（与主色一致，不刺眼） |
| 加载中 | `#B8A9C9` | loading 动画、生成中状态 |

### 禁止使用的颜色

```text
高饱和粉色（#FF69B4、#FF1493 等）
大红大紫（#FF0000、#9400D3）
霓虹渐变
强烈科技蓝（#0066FF、#00CCFF）
纯黑（#000000）
高对比荧光色
```

## 3. 字体系统

### 字体选择

```text
中文标题：思源宋体（Noto Serif SC）或系统默认宋体回退
中文正文：系统默认无衬线（-apple-system, "PingFang SC", "Noto Sans SC", sans-serif）
英文/数字：SF Pro Text、Helvetica Neue、系统默认
```

原则：不引入过多 web font，避免加载延迟。用系统字体保证阅读舒适度。

### 字号层级

| 层级 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 28px / 1.75rem | 600 | 首页主标题、页面大标题 |
| 区块标题 | 20px / 1.25rem | 600 | 选择页标题、剧情卡标题 |
| 卡片标题 | 18px / 1.125rem | 600 | 角色名、菜单标题 |
| 正文 | 16px / 1rem | 400 | 聊天内容、页面正文 |
| 辅助文字 | 14px / 0.875rem | 400 | 时间戳、提示、标签 |
| 极小文字 | 12px / 0.75rem | 400 | 版权、底部提示 |

### 行高

```text
标题：1.4
正文：1.6
聊天气泡文字：1.5
```

## 4. 间距系统

### 基础单位

以 `4px` 为基准：

```text
xs: 4px
sm: 8px
md: 16px
lg: 24px
xl: 32px
2xl: 48px
3xl: 64px
```

### 页面边距

```text
移动端：16px 左右边距
桌面端：页面最大宽度 720px，居中展示，两侧留白
```

### 圆角规范

| 元素 | 圆角 |
|------|------|
| 按钮 | 24px（胶囊形） |
| 输入框 | 16px |
| 气泡 | 16px（左下/右下根据方向调整） |
| 卡片 | 20px |
| 头像 | 50%（圆形） |
| 弹层/菜单 | 16px |
| 图片 | 12px |

## 5. 阴影与边框

### 阴影

```text
极轻阴影：0 1px 3px rgba(74, 68, 65, 0.06)
轻阴影：0 2px 8px rgba(74, 68, 65, 0.08)
卡片阴影：0 4px 16px rgba(74, 68, 65, 0.06)
```

原则：阴影非常轻，几乎不可察觉，只提供微弱层次。

### 边框

```text
分割线：1px solid #E8E2DC
输入框边框：1px solid #D9D3CE
输入框聚焦：1px solid #D4A5A5 + 柔和外发光
```

## 6. 组件规范

### Button

```text
主按钮：
  - 背景：#D4A5A5
  - 文字：#FFFFFF
  - 圆角：24px
  - 内边距：12px 32px
  - 字号：16px / 600
  - hover：#C99595，微上移 translateY(-1px)
  - disabled：opacity 0.5，cursor not-allowed

次按钮：
  - 背景：transparent
  - 文字：#4A4441
  - 边框：1px solid #D9D3CE
  - 其余同主按钮

文字按钮：
  - 无背景无边框
  - 文字：#8A827E
  - hover：#4A4441
```

### Input

```text
- 背景：#FFFFFF
- 边框：1px solid #D9D3CE
- 圆角：16px
- 内边距：12px 16px
- 字号：16px
- 占位符色：#A69E9A
- 聚焦：边框变 #D4A5A5，外发光 0 0 0 3px rgba(212, 165, 165, 0.15)
```

### CharacterCard（男友卡片）

```text
- 背景：#FFFFFF
- 圆角：20px
- 阴影：0 4px 16px rgba(74, 68, 65, 0.06)
- 内边距：24px
- 图片区：顶部，圆角 16px，宽高比 3:4 或 1:1
- 角色名：18px / 600 / #4A4441
- 短标签：14px / 400 / #B8A9C9
- 介绍文字：14px / 400 / #8A827E / 行高 1.6
- hover：微上移 translateY(-2px)，阴影加深
```

### ChatBubble（聊天气泡）

**男友气泡：**
```text
- 背景：#F0EBE6
- 边框：1px solid #E8E2DC
- 圆角：16px 16px 16px 4px（左下略尖）
- 内边距：12px 16px
- 最大宽度：70%
- 文字：16px / 400 / #4A4441
```

**用户气泡：**
```text
- 背景：#E8D5D5
- 边框：1px solid #D4C4C4
- 圆角：16px 16px 4px 16px（右下略尖）
- 其余同男友气泡
```

### VoiceBubble（语音气泡）

```text
- 同对应气泡样式
- 内部包含：播放图标 + 时长文字 + 波形占位
- 播放中：图标微动画（缩放或脉冲）
```

### ImageBubble（图片气泡）

```text
- 同对应气泡样式，但内边距更小（4px）
- 图片圆角：12px
- 最大宽度：60%
- 点击展开大图预览
```

### LoadingBubble（正在输入中）

```text
- 背景：#F0EBE6
- 圆角：16px
- 内边距：16px 20px
- 内容：三个渐变圆点动画
- 圆点色：#B8A9C9
- 动画：依次缩放，柔和呼吸感
```

### FailedBubble（失败状态）

```text
- 同对应气泡样式
- 文字色：#8A827E
- 附加：轻量重试按钮（文字按钮样式）
```

### TopBar（聊天顶部栏）

```text
- 背景：#FAF7F5（与页面背景一致，无分割）
- 高度：56px
- 底部：1px solid #E8E2DC（微弱分隔）
- 左侧：返回按钮 + 角色头像（36px 圆形）+ 角色名（16px / 600）
- 右侧：更多按钮（三点图标）
```

### BottomInputBar（底部输入区）

```text
- 背景：#FFFFFF
- 顶部边框：1px solid #E8E2DC
- 内边距：12px 16px
- 左侧：语音按钮（圆形，36px）
- 中间：输入框（自适应宽度）
- 右侧：+ 号按钮 + 发送按钮
- 安全区域适配：底部加 env(safe-area-inset-bottom)
```

### ShareCard（分享卡片）

```text
- 背景：#FAF7F5 或 #FFFFFF
- 圆角：16px
- 内边距：24px
- 顶部：角色头像 + 角色名
- 中间：聊天片段 或 男友图片
- 底部：钩子文案 + 产品名 + 网站链接
- 整体风格：干净、有留白、不拥挤
```

## 7. 页面视觉规范

### 首页 `/`

```text
布局：左右布局（桌面端）/ 上下布局（移动端）

左侧：
  - 主标题：28px / 600 / #4A4441
  - 副标题：16px / 400 / #8A827E / 行高 1.6
  - 按钮：主按钮样式
  - 18+ 提示：14px / 400 / #A69E9A
右侧：
  - 四位男友极简卡片
```

```text

18+ 勾选：自定义 checkbox，柔和粉色
按钮：主按钮，全宽
切换链接：文字按钮样式
```

### 基础档案页 `/onboarding`

```text
背景：#FAF7F5
内容居中，最大宽度 400px
标题：24px / 600
输入框：Input 组件规范
提示文字：14px / #8A827E
按钮：主按钮，全宽
```

### 男友选择页 `/characters`

```text

  - 移动端：1 列
  - 桌面端：2 列

卡片内包含：
  - 角色图（占位或真实图）

  - 短标签
```

```text

文案区：
  - 大留白
  - 文字：16px / 400 / #4A4441 / 行高 1.8
  - 文字有呼吸感，不拥挤

```

### 聊天页 `/chat/:characterId`

```text
整体背景：#FAF7F5
顶部：TopBar 组件

  - 可滚动区域
  - 底部留够输入区高度

  - 空状态：居中，"先打个招呼吧"，16px / #A69E9A
```

### 聊天记录页 `/chat/:characterId/history`

```text
背景：#FAF7F5
顶部：返回按钮 + "聊天记录" 标题
日期列表：
  - 每个日期一行
  - 16px / 400 / #4A4441
  - 底部边框 1px solid #E8E2DC
  - 点击后返回聊天页并定位
```

## 8. 响应式布局

### 断点

```text
移动端：< 768px
桌面端：>= 768px
```

### 核心规则

```text
移动端：
  - 页面内容全宽
  - 聊天页全屏
  - 输入区固定底部，适配安全区

桌面端：
  - 页面最大宽度 720px，居中
  - 两侧留白，背景保持 #FAF7F5
  - 聊天页居中展示，像手机模拟器
```

## 9. 加载状态

### 页面加载

```text
- 页面整体淡入，duration 300ms
- 内容依次出现，stagger 50ms
- 不使用旋转 loading 图标占满全屏
```

### 按钮加载

```text
- 主按钮 loading：显示微缩脉冲动画，按钮文字变为 "发送中……"
- 不显示外部 spinning 图标
```

### 聊天加载

```text
- 历史消息加载：顶部弱提示 "加载中……"，14px / #A69E9A
- 男友回复中：LoadingBubble 组件，三个呼吸圆点
```

---

## 10. 失败状态

### 通用失败

```text
- 不显示红色错误框
- 不使用 toast 通知
- 在对应消息位置显示 FailedBubble
- 文案："他刚刚没发出去，再试一次" 或对应具体文案
- 提供轻量重试按钮
```

### 网络异常

```text
- 页面顶部弱提示："现在有点不稳定，稍后再试"
- 背景：#F5F0EC
- 文字：14px / #8A827E
- 自动消失
```

## 11. 空状态

### 空聊天

```text
- 居中显示："先打个招呼吧"
- 16px / #A69E9A
- 无图标，保持极简
```

### 空选择页

```text
- 理论上不会出现（四位男友固定展示）
- 若出现："稍等一下，角色正在准备中"
```

## 12. 动画与过渡

### 原则

```text
柔和、自然、不突兀。
动画是辅助，不是主角。
```

### 常用动画

```text
页面切换：fade-in，300ms，ease-out
气泡出现：scale(0.95) + opacity(0) → scale(1) + opacity(1)，200ms，ease-out
按钮 hover：translateY(-1px) + 背景色变化，150ms
输入框聚焦：边框色变化 + box-shadow 出现，150ms
加载圆点：scale 呼吸动画，1.2s 循环，ease-in-out
```

## 15. 禁止风格清单

以下视觉风格在《纸片人男友》中禁止使用：

```text
乙女页游感：
  - 华丽边框、金色描边、闪动特效
  - 抽卡动画、星级标识、进度条装饰
  - 过度二次元角色立绘风格

AI 工具感：
  - 科技蓝主色调
  - 代码块、参数面板、模型选择器
  - 机器人图标、齿轮图标

SaaS 后台感：
  - 左侧导航栏、顶部面包屑
  - 数据表格、筛选器、操作按钮组
  - 仪表盘、统计卡片

过度甜腻：
  - 高饱和粉色、大红心形、玫瑰背景
  - "宝贝""亲爱的"等过度亲密文案作为 UI 元素
  - 过度可爱的 emoji 和贴纸

通用 AI 感：
  - 紫色渐变、模糊光斑背景
  - 过度使用 glassmorphism（玻璃拟态）
  - 千篇一律的圆角卡片网格
```
